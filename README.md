# AI-Based Hiring Prediction System

A Machine Learning project that predicts recruiter hiring decisions based on candidate information.

## Project Overview

This project uses a dataset containing candidate-related information and a target variable called **Recruiter Decision**.

The target is converted into:

- `Hire = 1`
- `Reject = 0`

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- Machine Learning

## Project Workflow

1. Load the dataset
2. Explore the data
3. Check missing values
4. Analyze the target variable
5. Separate features and target
6. Encode categorical features
7. Scale numerical features
8. Split data into training and testing sets
9. Train Machine Learning models
10. Evaluate model performance

## Machine Learning

The project prepares the data for classification of recruiter decisions.

## Dataset

The dataset contains candidate-related features used to predict the recruiter's hiring decision.

## Project File

`AI_Based_Hiring_Prediction_System.ipynb` contains the Google Colab notebook with the implementation.
